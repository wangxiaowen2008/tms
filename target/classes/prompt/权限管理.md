在src目录下，我已经把框架的整体目录结构已经提供了，每个目录的功能如下，请根据框架来开发一个权限模块，包括菜单管理，角色管理，用户管理。权限控制到按钮级别，一个用户可以分别多个角色，一个角色可以分配多个菜单，一个菜单可以有很多操作按钮。

```
要求如下：
包路径：com.paob.tms
web\controller：控制器，处理HTTP请求
service：服务层，调用Mapper接口的方法dd
model：实体类，与表字段对应，跟表操作相关
mapper：MyBatis的Mapper接口，定义了数据库操作的方法
dto：实体类，页面请求的参数放在req类中，响应的数据放在resp类中，返回页面
mapping：使用mapstruct实现，进行bean的转换
resources\mapper：MyBatis的XML配置文件，定义了SQL语句
数据库：postgresql
技术：springboot3,mybatis-plus3
```

## 任务：

### 1.菜单管理

#### 			1.1 菜单查询

						查询条件包括：菜单名称，菜单状态，分页查询列表包括：菜单排序，菜单层级，上级菜单，菜单名称，菜单链接，页面操作按钮，菜单图标，菜单状态，更新人，更新时间。

####              1.2 新增菜单

						包括上级菜单，菜单层级，菜单名称，菜单排序，菜单链接，菜单按钮（可以添加多个按钮），菜单图标，菜单状态，更新人，更新时间

####              1.3 编辑菜单

                      根据菜单名称更新 上级菜单，菜单名称，菜单链接，菜单图标，菜单状态

### 2.角色管理

#### 		2.1 角色查询

#### 		3.2 新增用户

				包括um号，用户名称，邮箱，部门名称，角色名称，用户状态
