### 需求描述：

#### 	银行账户余额对账

1. **页面功能 - 查询字段说明**

   | 序号 | 特征 | 字段名称 | 数据来源 / 内容                | 备注     |
   | ---- | ---- | -------- | ------------------------------ | -------- |
   | 1    | 字段 | 日期     | 日期，必填                     | 默认昨天 |
   | 2    |      | 银行     | 下拉框，来源付款账户           |          |
   | 3    |      | 银行账户 | 下拉框，来源付款账户           |          |
   | 4    |      | 币种     | 下拉框，来源付款账户           |          |
   | 5    |      | 金额     |                                |          |
   | 6    |      | 对账差异 | 下拉框，枚举值：有差异、无差异 |          |
   | 7    | 操作 | 查询     | 执行查询                       |          |
   | 8    |      | 重置     | 重置查询条件                   |          |
   | 9    |      | 下载列表 | 下载列表对应的数据             |          |
   
2. **列表展示 - 列表字段说明**

   | 序号 | 特征 | 字段名称           | 备注                     |
   | ---- | ---- | ------------------ | ------------------------ |
   | 1    | 字段 | 序号               | 按日期倒序、银行账户正序 |
   | 2    |      | 日期               |                          |
   | 3    |      | 银行               |                          |
   | 4    |      | 银行账户           |                          |
   | 5    |      | 币种               |                          |
   | 6    |      | 银行账户余额       |                          |
   | 7    |      | 银行账户对应科目   |                          |
   | 8    |      | 银行账户对应子目   |                          |
   | 9    |      | 科目余额表期末余额 |                          |
   | 10   |      | 对账差异           |                          |
   | 11   |      | 对账差异金额       |                          |

   ​    列表按日期倒序、银行账户正序

**3. 对账逻辑**

- **银行账户余额**：取付款账户，匹配运营导入银行账户余额。
- **科目余额表期末余额**：取付款账户对应的科目、子目、币种，匹配科目余额表，得到期末余额

**4. 对账差异邮件提醒**
